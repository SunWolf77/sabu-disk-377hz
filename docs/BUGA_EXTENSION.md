# Volumetric cousins (optional extension)

**Role in this repo:** teaching / volumetric *question* — **not** the Sabu disk null-test.

Hypothesis only: Sabu is a **planar** object (disk/bowl modes). A hollow sphere or a ported polyhedron would be **volumetric** (cavity modes). Same *kind* of question, different geometry. That is why these names appear here. It is **not** a measured lattice and not a shared results table.

## Roman dodecahedron

Gallo-Roman hollow bronze 12-face objects with holes of mixed size. Function **unknown** (same honest box as Emery on JE 71295).  
This repo hosts **no** dodecahedron mesh, protocol, or data. Mentioned only as another volumetric / ported-shell *question*. Do not file it under Sabu Mode A.

## Claim hygiene

- Fibonacci lines in the Buga scripts are **markers**, not measured peaks on a physical sphere.
- Public media claims about a “Buga Sphere” (Colombia, 2025–) are **outside** this repository’s L1 data.
- No ferrofluid, CT, or alloy result in this repo is tied to those scripts.
- Real acoustic work on any sphere or dodecahedron would need its **own** pre-register, null control, and `mic_` files — same standard as Sabu (`docs/NULL_TEST.md`).
